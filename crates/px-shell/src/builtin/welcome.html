A page drawn by our own engine

Everything in this area was parsed, styled, laid out, painted and rasterised by the engine in this repository. The tabs and the address bar around it are the browser chrome.

Inline text

Spans, links, wrapping and line breaking at the window width. Resize the window to see it reflow.

Flexbox

These cards are a wrapping flex row. See also the flex page.

Scrolling

Mouse wheel, Page Up and Down, Home, End and the arrow keys scroll a long page: open it.

Links to local files work too. Open a file with px-shell path/to/page.html or type its path in the address bar.
