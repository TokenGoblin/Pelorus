Privacy

What this browser does and does not do. Each line is a rule the build is held to, and each can be checked.

Compiled out

No telemetry

No telemetry, crash reporting, safe-browsing beacon or captive-portal probe is compiled in. There is no first-run call home.

Design rule

Pages and patches only

Traffic is a page you asked for, and a signed update check, weekly by default. The check carries no identifiers.

Design rule

State is partitioned

Cookies, cache, storage, connections, DNS and TLS sessions are kept apart for each top-level site. A site cannot follow you to another through them.

Design rule

No JIT

JavaScript runs in an interpreter. There is no compiler to attack. Script-heavy pages run slower, and that is accepted.

Status not reported yet

Pages run in a sandbox

Page processes reach files, network and clipboard only through the browser process. If the sandbox cannot be applied, the browser does not start.

Design rule

Quiet by default

No feed, no onboarding, no promotions, no badges. Notifications are asked for only after you have used a site.

What this does not cover

It does not defend against someone with administrator access to this computer, someone with physical access to it, or an attacker holding a complete chain of unreported flaws.

It makes no claim about blocking advertising or malware in general.
